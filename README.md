# DW2 · Interface Organizer

自用的 TauriTavern / SillyTavern 界面整理扩展。当前版本 **0.1.5-beta.1**，iPhone 实机仍需逐项验收。

## 只整理三个位置

- **三横菜单 → 更多工具**：原生低频工具统一收纳到「更多工具」；触发器沿用 TT 菜单本身的主题，不额外套皮肤；**不在三横菜单增加「界面整理」入口**。
- **魔法棒 → 更多工具**：在扩展设置页的「DW2 · 界面整理」中逐项选中需要收纳的入口。魔法棒底部会出现「更多工具（N）」，点开后已收纳的原生入口在其下方展开，保留原按钮的监听器；关闭整理、取消勾选时恢复原位置。
- **扩展设置页 → 单列与原生折叠**：保持 TT 原有按钮、监听器和插件设置节点；使用原生折叠栏外观展示「更多扩展设置」，并将它置于顶部「管理扩展 / 安装扩展」工具栏下方、原生「正则」设置上方；在外层统一系统工具、酒馆助手、DW2 与其他插件的视觉顺序。旧 Extras API 区可独立收纳。

不修改预设、正则、用户设置、世界书、聊天或 API 地址。原生正则编辑器内部控件不应用额外美化和强制重排。

## 安装与更新

TT → 扩展 → 安装扩展，填写：

```
https://github.com/dw2devil1024-creator/dw2-interface-organizer
```

安装或更新后刷新 TT。后续使用 TT 的 **管理扩展 → 检查更新 / 更新** 即可，不会静默更新。原来的设置随 TT 账号保存。

## 设置入口与恢复

唯一的设置入口在 **扩展设置页 → ✧ DW2 · Interface Organizer（S.A. · DW2）**。展开后可以直接启用/停用整理、打开详细设置、**检查并更新**、打开原生扩展管理、**刷新酒馆**（有二次确认）。

三个模块均可单独开关；「恢复原界面」关闭全部整理并取消收纳。魔法棒隐藏只影响入口可见性，不停用原有插件。

## v0.1.4-beta.1 变化

1. 「更多扩展设置」挪至顶部原生管理工具栏下、正则栏上；展开内容按顺序向下显示。
2. 「DW2 · 界面整理」保持整个扩展列表最末尾，不随「更多扩展设置」迁移。
3. 启用整理控件改为灰白滑动开关，避免 iOS 默认蓝色勾选；功能不变。
4. 三横菜单与魔法棒保持 v0.1.2 的正常交互，不改预设、正则或世界书。

## v0.1.4-beta.1 布局修复

上一版的外层扩展排序仍然无效，是因为 TT 原生 `.extension_container` 使用 `display: contents`，这类元素本身没有布局盒子，无法依靠 flex `order` 排序。

这次只把 `#extensions_settings` 和 `#extensions_settings2` 的**直接子容器**恢复为可排序的布局项，避免影响正则、预设及其他插件内部 DOM：

- 「更多扩展设置」：原生扩展管理工具栏之后，原生「正则」之前，展开条目在下方。
- 「DW2 · 界面整理」：整个列表最后。
- 未选择收纳的扩展仍保持可用，原有展开/收起设置不变。
- 三横菜单、魔法棒、灰白开关未作逻辑改动。

## 已知边界

- 目前是 **测试版**，代码通过语法、魔法棒 DOM 展开与恢复、配置兼容性模拟检查；还需要你 iPhone 的 TT 实机验收。
- 极少数将点击事件绑在原按钮父节点上的第三方入口，移动后可能需要兼容修复；遇到这种按钮可以暂时取消对它的收纳。
- 插件自己提供的「检查并更新」会调用 TT 现有扩展更新接口，点击它可能直接安装可用更新，而不只是显示提示。想分步确认可使用 TT 原生「管理扩展」。
