# DW2 · Interface Organizer

个人使用的 TauriTavern / SillyTavern 界面整理扩展，当前版本 **0.1.0-beta.1**，处于测试阶段。

## 功能
- **三横菜单**：将低频原生工具折叠至「更多工具」，沿用原生按钮和处理器。
- **魔法棒入口**：逐项识别、隐藏与恢复原生及第三方入口，不停用插件。
- **扩展设置**：整理为单列布局，将指定的低频设置收入「更多扩展设置」，可随时恢复。

不修改预设、世界书、聊天、正则、API 设置或 TT 核心代码。不含预设高级参数折叠与正则编辑器美化，以避免同 DW2 Resource Library 的相关模块重叠。

## 安装
TauriTavern → 扩展 → 安装扩展，粘贴下面的公开 Git 地址：

```text
https://github.com/dw2devil1024-creator/dw2-interface-organizer
```

安装后刷新 TT。在输入栏左侧三横菜单中选择「⚙ 界面整理」，或进入扩展设置页找到 DW2 · 界面整理。

扩展使用 TT 原生 Git 更新入口；不会静默自动更新。

## 默认与恢复
初次启用时，三横菜单收纳五种常见低频工具；魔法棒不隐藏任何入口；扩展设置采用单列，但不自动收纳已有扩展。你可以在设置里逐项选择，也可以点击「恢复原界面」。

## 兼容提示
这是一份尚未通过 iPhone TauriTavern 实机验收的候选版本。三横菜单收纳会移动选定的**原生 DOM 节点**并保留原有监听器；需要在所用 TT 版本、主题和 DW2 插件组合下逐项测试。扩展页只处理外层列表排布，不改正则编辑器内部结构。

测试重点：菜单展开和按钮点击、魔法棒入口显隐、扩展设置折叠后内部按钮可用、刷新后状态恢复、DW2 预设和正则分组保持原样。
