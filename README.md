# DW2 · Interface Organizer

自用的 TauriTavern / SillyTavern 界面整理扩展。当前版本 **0.1.1-beta.1**，iPhone 实机仍需逐项验收。

## 只整理三个位置

- **三横菜单 → 更多工具**：原生低频工具统一收纳到「更多工具」；触发器沿用 TT 菜单本身的主题，不额外套皮肤；**不在三横菜单增加「界面整理」入口**。
- **魔法棒 → 更多工具**：在扩展设置页的「DW2 · 界面整理」中逐项选中需要收纳的入口。魔法棒底部会出现「更多工具（N）」，展开时暂时显示原本隐藏的原生入口。为保护原生事件，展开后入口仍处于原先列表位置，不克隆或搬动其元素。
- **扩展设置页 → 单列与原生折叠**：保持 TT 原有按钮、监听器和插件设置节点；使用原生折叠栏外观展示「更多扩展设置」；在外层统一系统工具、酒馆助手、DW2 与其他插件的视觉顺序。旧 Extras API 区可独立收纳。

不修改预设、正则、用户设置、世界书、聊天或 API 地址。原生正则编辑器内部控件不应用额外美化和强制重排。

## 安装与更新

TT → 扩展 → 安装扩展，填写：

```
https://github.com/dw2devil1024-creator/dw2-interface-organizer
```

安装或更新后刷新 TT。后续使用 TT 的 **管理扩展 → 检查更新 / 更新** 即可，不会静默更新。原来的设置随 TT 账号保存。

## 设置入口与恢复

唯一的设置入口在 **扩展设置页 → DW2 · 界面整理 → 打开界面整理**。

三个模块均可单独开关；「恢复原界面」关闭全部整理并取消收纳。魔法棒隐藏只影响入口可见性，不停用原有插件。

## v0.1.1-beta.1 变化

1. 魔法棒增加可展开的「更多工具」，保留原生入口与原有事件。
2. 删除三横菜单中的「⚙ 界面整理」按钮；「更多工具」继承原生菜单主题。
3. 扩展设置采用原生折叠栏标题，稳定整理外层类别顺序，可选收纳旧 Extras API。
4. 保留已有设置，版本资源添加缓存标记，TT 更新后刷新即可加载。

## 已知边界

- 目前是 **测试版**，已通过 JS 语法、配置迁移、排序优先级检查；还没有完成新版 iPhone + 透明主题组合的实机回归。
- 魔法棒为避免破坏插件父级事件，展开时显示入口在原位置，而不是移到「更多工具」面板下。若实际使用需要真正的内嵌列表，需要后续评估事件兼容。
- 第三方主题若重写原生扩展设置容器，需要手机上测试「更多扩展设置」打开和关闭后全部按钮是否正常。
