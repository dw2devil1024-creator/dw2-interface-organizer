iPhone 实机复测发现，上一版点击「区域 10」仍然跳到前一个「09-F」区块。以使用者实测准确的 SillyTavern-ThemeEditor 原生 CSS 搜索为行为参照，修复本插件的搜索定位：

- **重建点击定位逻辑**：根据当前 `#customCSS` 的真实最新内容重新取得被点击的匹配行及搜索词，按原始行换行符累加计算准确字符偏移，调用 `focus()` 与 `setSelectionRange()` 选中搜索词。
- **采用原版可靠的坐标计算方式**：临时创建与原生 CSS textarea 排版属性一致的普通隐藏 `div`，将目标光标前的文字与短标记装入，读取标记的 `offsetTop`；随后立刻移除临时节点，以 `textarea.scrollTop = offsetTop - paddingTop` 直接滚动编辑框。取消上一版额外的 Shadow DOM、`scrollIntoView()` 和多帧 `requestAnimationFrame` 校正，以免不同机制互相竞争滚动。

- **范围**：只改 `theme-studio.js` 的搜索定位和界面提示，以及 CSS 工作台专属的一条废弃提示样式。未改原生 CSS 内容、世界书、主题色或其他 DW2 插件。
- **验证**：与原版仓库 `n-nakari/SillyTavern-ThemeEditor` 的实际代码核对过处理流程，完成 JS 语法、关键词偏移及版本引用静态核验；**真正的 iPhone 2.3 滚动表现仍以实机验收为准**。

## v0.1.27-beta.1 · 修复 iPhone CSS 搜索定位偏移

根据 iPhone 用户实测：输入「背景」找到三个匹配结果，点击第 2604 行的第三条，原生 CSS 编辑框却跳到看不到「背景」的位置。根因是原有定位按原始行数乘行高估算像素偏移；但 CSS 长行在手机上自动换行，一个原始行会占据数行可见高度，越往后偏差越大。

- 改为 **按真实自动换行后的排版位置定位**：点击结果时临时创建只读的 Shadow DOM 测量节点，拷贝当前原生 `#customCSS` 文本框字号、行高、左右内边距、字距、宽度等参数，并测量匹配文本的实际竖向坐标，随后立即移除测量节点。不修改代码，也不永久增加隐藏元素。
- **选中目标关键词**：点击搜索结果会聚焦原生 CSS 编辑框，选中匹配文字，并调整编辑框内部滚动位置，尽量将其显示在可见区域靠上的位置。取消此前可能引起定位竞争的平滑整框滚动。iOS 上两帧内再次校正内部滚动，减少 WebKit 光标移动后的跳动。
- 搜索结果、中文注释搜索、保存／另存、首尾跳转、扩框、三种外观、默认独立开关全部保持原状。世界书与其他功能没有代码改动。
- 已用浏览器移动视口中超过 2600 行、包含自动换行的 CSS 进行算法模拟，验证可以选中「背景」并将它滚动至对应区域；仍需在 TT 2.3 iPhone 设备实测。

首次实机验证建议：备份世界书，在 TT 2.3.0 中切换世界书、搜索、编辑关键词及正文、调整深度与顺序、切换三分区、关闭开关恢复原版、再次启用、换浅色/深色主题检查。当前仅完成静态和模拟测试，不标记为稳定正式版。

## 只整理四个位置

- **三横菜单 → 更多工具**：原生低频工具统一收纳到「更多工具」；触发器沿用 TT 菜单本身的主题，不额外套皮肤；**不在三横菜单增加「界面整理」入口**。
- **魔法棒 → 更多工具**：在扩展设置页的「DW2 · 界面整理」中逐项选中需要收纳的入口。魔法棒底部会出现「更多工具（N）」，点开后已收纳的原生入口在其下方展开，保留原按钮的监听器；关闭整理、取消勾选时恢复原位置。
- **扩展设置页 → 单列与原生折叠**：保持 TT 原有按钮、监听器和插件设置节点；使用原生折叠栏外观展示「更多扩展设置」，并将它置于顶部「管理扩展 / 安装扩展」工具栏下方、原生「正则」设置上方；在外层统一系统工具、酒馆助手、DW2 与其他插件的视觉顺序。旧 Extras API 区可独立收纳。
- **世界书 → 清透布局**：第四个独立开关，紧凑的世界书选择／搜索／排序、可折叠原生管理工具栏、四栏条目参数和三分区；主题自适应，不修改数据。

不修改预设、正则、用户设置、世界书内容、聊天或 API 地址。仅在独立开关开启时整理 TT 世界书编辑器布局；顶部管理按钮、搜索、排序和分页使用原生节点，并在关闭时归位，原生输入与保存机制保持不变；正则编辑器内部控件不应用额外美化和强制重排。

## 已知边界

- 目前是 **测试版**，世界书布局增加了显示分区和可逆开关；代码通过语法与静态兼容性检查，仍需 iOS、Android 的 TT 实机验收。
- 极少数将点击事件绑在原按钮父节点上的第三方入口，移动后可能需要兼容修复；遇到这种按钮可以暂时取消对它的收纳。
- 插件自己提供的「检查并更新」会调用 TT 现有扩展更新接口，点击它可能直接安装可用更新，而不只是显示提示。想分步确认可使用 TT 原生「管理扩展」。
