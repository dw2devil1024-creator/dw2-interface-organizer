- 移动真实 TT 输入及勾选节点，不复制或重建控件；每个原位置保存占位标记，关闭世界书清透布局后恢复原生顺序。
- 不改变世界书数据、原生触发算法和自动保存逻辑。仅静态语法核验，尚未完成 iPhone 实机验收；待测试 Select2 多选、优先级及排除勾选、折叠后滚动行为。

## v0.1.10-beta.1 · 世界书整页防横滑＋折叠工具栏与标题微调

根据 iPhone 第二轮截图，仅调整已开启「世界书 · 清透布局」的世界书顶部和**未展开**的原生条目。

- **修复整个世界书面板左右移动**：上一版只对 `#world_popup` 做横向溢出裁切，TT 外层固定抽屉 `#WorldInfo` 仍可能发生横向滚动。开启新布局时在其外层添加独立 class，限制 `#WorldInfo`、`#wi-holder` 和列表的水平溢出，并允许正常纵向手指滑动；关闭时立即移除 class，恢复 TT 原布局。挂载时清空先前留下的抽屉水平偏移。
- **管理工具两排**：展开小折叠后，12 个原生功能图标排列成等宽的**单排 12 列**；原生分页容器另起一排，包含区间说明、翻页和每页条数。都在布局宽度内处理，**完全取消工具带内部横向滑动**；极窄屏分页可自然换行。
- **轻量管理入口**：折叠标题只保留细小的「☷ 管理工具」文字图标，不加外边框、填充底色或额外三角形。继续使用原生 `<details>` 折叠机制。
- **可点击的原生图标**：仍移动 TT 原按钮节点，不克隆、不修改点击事件。创建世界书原生按钮在紧凑图标模式隐藏长文字时增加临时标题及辅助阅读标签，关闭新布局恢复原属性。
- **标题及蓝色状态框统一**：两个控件外框均为 36px 高、盒模型相同；标题 textarea 使用 18px 行高及上下 8px 内边距，使单行标题文字视觉垂直居中。保留原生输入和保存逻辑。
- **已经验收的部分不动**：世界书选择器／搜索／优先级的三列布局、卡片右上角原生移动／复制／删除图标，以及「位置、深度、顺序、触发」四列并排不变。展开后的正文／触发规则／高级设置保留上版原逻辑。
- **独立回退**：扩展设置「世界书 · 清透布局」开关关闭，会移除外层防横滑 class、管理工具、额外控件标签和分区按钮，按原顺序归还搜索、排序、12 个管理按钮与分页容器，不污染 TT 原生 world info 控件及 Resource Library 世界书下拉分组。
- **主题跟随**：继续从 TT 的 SmartTheme 样式继承颜色，没有新的固定配色。

请在 TT 2.3.0 的 iPhone 上分别检查：世界书打开后横向滑动不会拖动整块面板、管理工具展开图标一排而分页单独一排、标题文字垂直居中、两框同高、再关闭独立开关恢复原版。此版本仍为待实机验收的 beta。

## v0.1.9-beta.1 · 世界书顶部与未展开条目精修

根据 iPhone 实机截图，集中修复第一版世界书新布局的横向页面溢出和过大的搜索／排序输入。

- **顶部第一排**：保留 Resource Library 已经管理的 TT 原生世界书选择器，旁边把原生「搜索」和「优先级／排序」并排压紧，三者按容器宽度自适应且不触发整个世界书页面的横向滑动。世界书名称较长时只在选择器里截断显示，打开仍可完整选取。
- **第二排折叠工具栏**：新增一个很小的「管理工具」原生 details/summary。默认折叠；展开后把「创建世界书、导入／导出、重命名、复制世界书、删除世界书、新建条目、展开／折叠全部、批量标题、应用排序、刷新、原生分页和每页条数」放在单行工具带中；如果一行放不下，只允许这个工具带内部左右滑动。
- **真实原生功能**：所有工具和搜索／排序都移动 TT 的**同一个原生 DOM 节点**，不复制或虚构按钮、不重绑保存逻辑；每个位置由注释占位符记录，关闭新布局或停用扩展时按原顺序完整归位。世界书 Select2 原生节点完全留在原位，避免打断 Resource Library 分组。
- **未展开条目**：将「移动／复制到其他世界书」（双箭头）、「复制条目」和「删除条目」三个 TT 原按钮用 CSS 并排固定在每张卡片右上角；仅移动视觉位置，不移动这些节点，也不更换任何事件。
- **条目标题与蓝色状态选择器**：共同设为 36px 高，收紧左右间距。
- **位置、深度、顺序、触发 %**：手机上恢复为四栏并排，避免第一版自动分两排造成的卡片过高。强制子项最小宽度为零，禁止内容把页面撑宽。
- **仅此范围**：本次不改原生世界书数据、搜索过滤、编辑保存，也暂不重新设计展开条目的正文／触发／高级三分区；三横菜单、魔法棒、扩展设置、Resource Library 和正则功能均保持不变。
- **回退**：扩展设置中「世界书 · 清透布局（关闭恢复原版）」开关保持默认关闭；关掉后工具栏与布局 class 都移除，原生按钮搜索分页恢复到原来的父节点。
- **主题**：继续使用 TT 的 SmartTheme 文字、边框与底色变量，没有指定固定深灰、粉蓝或白色主题。

兼容性依据为 TauriTavern 官方 v2.3.0 `src/index.html` 与世界书原生编辑器结构；通过源码和动态 DOM 模拟，仍需 iPhone 和 Android 真实设备检查横向滚动、操作和布局还原。

## v0.1.8-beta.1 · 世界书清透布局（跟随 TT 主题）

新增第四项可选的原生世界书编辑器布局，独立于原先三个整理模块：

- **入口**：TT → 扩展设置 → ✧ DW2 · Interface Organizer 下方直接显示「世界书 · 清透布局（关闭恢复原版）」开关；详细「打开界面整理」面板里也有第四个「世界书」模块。
- **默认关闭**，方便升级后先确认旧功能正常。打开后仅对 TT 原生世界书编辑器 `#world_popup` 添加一个样式开关，不改 Select2 分组选项或 Resource Library 的世界书分组与选中状态。
- **选择世界书全宽**：原生下拉选择器独占一行，创建、导入、导出、重命名、复制、删除等原按钮继续保留。
- **搜索全宽**：世界书条目搜索输入框独占一整行，下方保留原生排序、展开、折叠、分页与其他操作按钮。
- **条目清透卡片**：保留原生列表顺序、拖拽手柄、启用开关、条目名称、状态、位置、深度、顺序和触发百分比；只优化窄屏宽度、标题与网格排列。
- **三分区**：条目原生展开时新增「正文 / 触发规则 / 高级设置」按钮。正文默认显示关键词、原生正文与备注；触发规则显示关键词匹配、条目覆盖参数与触发模式；高级设置显示递归、包含组、权重、冷却／延迟、筛选器和其他原生设置。原生控件节点和事件保持不变，只按分区决定可见性。
- **主题跟随**：新布局的文字、边框与淡底色取自 TT SmartTheme 变量，没有写死深色／浅色主题；跟随当前主题自动适配。
- **可逆**：关闭世界书开关或停用 Interface Organizer，会移除增强类名和分区按钮，所有 TT 原生条目及控件保持原样。主开关「启用界面整理」关闭时也会暂时停用世界书布局。
- **互不干涉**：原三横菜单、魔法棒、扩展设置单列整理保持原逻辑；不移动世界书控件、改写世界书数据或触发额外保存；正则、预设和聊天界面均不受影响。

首次实机验证建议：备份世界书，在 TT 2.3.0 中切换世界书、搜索、编辑关键词及正文、调整深度与顺序、切换三分区、关闭开关恢复原版、再次启用、换浅色/深色主题检查。当前仅完成静态和模拟测试，不标记为稳定正式版。

## 只整理四个位置

- **三横菜单 → 更多工具**：原生低频工具统一收纳到「更多工具」；触发器沿用 TT 菜单本身的主题，不额外套皮肤；**不在三横菜单增加「界面整理」入口**。
- **魔法棒 → 更多工具**：在扩展设置页的「DW2 · 界面整理」中逐项选中需要收纳的入口。魔法棒底部会出现「更多工具（N）」，点开后已收纳的原生入口在其下方展开，保留原按钮的监听器；关闭整理、取消勾选时恢复原位置。
- **扩展设置页 → 单列与原生折叠**：保持 TT 原有按钮、监听器和插件设置节点；使用原生折叠栏外观展示「更多扩展设置」，并将它置于顶部「管理扩展 / 安装扩展」工具栏下方、原生「正则」设置上方；在外层统一系统工具、酒馆助手、DW2 与其他插件的视觉顺序。旧 Extras API 区可独立收纳。
- **世界书 → 清透布局**：第四个独立开关，紧凑的世界书选择／搜索／排序、可折叠原生管理工具栏、四栏条目参数和三分区；主题自适应，不修改数据。

不修改预设、正则、用户设置、世界书内容、聊天或 API 地址。仅在独立开关开启时整理 TT 世界书编辑器布局；顶部管理按钮、搜索、排序和分页使用原生节点，并在关闭时归位，原生输入与保存机制保持不变；正则编辑器内部控件不应用额外美化和强制重排。

## 安装与更新

TT → 扩展 → 安装扩展，填写：

```
https://github.com/dw2devil1024-creator/dw2-interface-organizer
```

安装或更新后刷新 TT。后续使用 TT 的 **管理扩展 → 检查更新 / 更新** 即可，不会静默更新。原来的设置随 TT 账号保存。

## 设置入口与恢复

唯一的设置入口在 **扩展设置页 → ✧ DW2 · Interface Organizer（S.A. · DW2）**。展开后可以直接启用/停用整理、打开详细设置、**检查并更新**、打开原生扩展管理、**刷新酒馆**（有二次确认）。

四个模块均可单独开关；「恢复原界面」关闭全部整理并取消收纳。魔法棒隐藏只影响入口可见性，不停用原有插件。

## v0.1.4-beta.1 布局修复

上一版的外层扩展排序仍然无效，是因为 TT 原生 `.extension_container` 使用 `display: contents`，这类元素本身没有布局盒子，无法依靠 flex `order` 排序。

这次只把 `#extensions_settings` 和 `#extensions_settings2` 的**直接子容器**恢复为可排序的布局项，避免影响正则、预设及其他插件内部 DOM：

- 「更多扩展设置」：原生扩展管理工具栏之后，原生「正则」之前，展开条目在下方。
- 「DW2 · 界面整理」：整个列表最后。
- 未选择收纳的扩展仍保持可用，原有展开/收起设置不变。
- 三横菜单、魔法棒、灰白开关未作逻辑改动。

## 已知边界

- 目前是 **测试版**，世界书布局增加了显示分区和可逆开关；代码通过语法与静态兼容性检查，仍需 iOS、Android 的 TT 实机验收。
- 极少数将点击事件绑在原按钮父节点上的第三方入口，移动后可能需要兼容修复；遇到这种按钮可以暂时取消对它的收纳。
- 插件自己提供的「检查并更新」会调用 TT 现有扩展更新接口，点击它可能直接安装可用更新，而不只是显示提示。想分步确认可使用 TT 原生「管理扩展」。
